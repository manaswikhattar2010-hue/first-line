CHAPTER II by candlelight

The Chamber of Names

Beyond the door lies a chamber lined with brass plaques, each engraved with a word and a memory sealed beside it. This is how the house remembers things — not by magic alone, but by naming.

In the spellbook's tongue, this is called a variable: a name you choose, holding whatever memory you give it. Engrave a plaque like the one below, and the chamber will remember it for the rest of your journey.

From the spellbook:
city = "Paris"
city now remembers "Paris"

Here, city is the name, and "Paris" is the memory stored inside it. Once a name holds a memory, you can speak that name anywhere you would have spoken the memory itself.

Try it yourself. Engrave a plaque that gives the name city the memory "Paris", exactly as shown above.
