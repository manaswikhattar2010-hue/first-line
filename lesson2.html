Variables

A variable is a name you give to a piece of information, so you can use it later without retyping it. Think of it like a labeled box: you put something in the box, and the label lets you find it again.

name = "Ava"
print(name)
Ava

Here, name is the label, and "Ava" is what's stored inside it. Once a variable holds a value, you can use the variable's name anywhere you'd use that value.

Try it yourself. Create a variable called city that stores the text "Paris", exactly like the example above.
