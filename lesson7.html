The Spiral Stair

The stairs before you don't end — they spiral downward, the same step repeating, until something tells them to stop.

In the spellbook's tongue, this is a for loop. It repeats whatever is indented beneath it, once for every number in a range you choose.

From the spellbook:
for step in range(3):
    print("You descend one step.")
You descend one step. You descend one step. You descend one step.

range(3) counts out three turns of the stair. step is just a name for wherever you are in the count — you don't have to use it. The indentation rule is the same one from the fork: only what's indented belongs to the loop above it.

Try it yourself. Write a for loop that repeats three times, printing something each time it does. The words are yours to choose — the house only cares that the loop takes the right shape.

The Second Question

The voice behind this door doesn't stop at one question. If your first answer doesn't satisfy it, it tries another — and sometimes another after that.

This is called elif, short for "else if." It lets a fork branch more than two ways: try the first condition, and if that's false, try the next, and the next, until one is true — or, if you add an else at the end, catch whatever's left.

From the spellbook:
if age >= 18:
    print("You may enter")
elif age >= 13:
    print("You may enter with a guardian")
else:
    print("Not tonight")
Only one of these ever speaks — whichever question is met first.

Try it yourself. Write an if, followed by at least one elif, each ending in a colon with an indented line beneath it. An else at the end is welcome, but not required. Use whatever condition and message you like — the house only cares about the shape.
