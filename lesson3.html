if statements

An if statement lets your code make a decision. It checks whether something is true, and only runs the code underneath it when that condition is met.

if age >= 18: print("You can vote")

Notice two things: the line ends in a colon :, and the line underneath is indented. That indentation is what tells Python "this only happens if the condition above is true."

Try it yourself. Write an if statement that checks whether age is 18 or older, and prints any message you like underneath. There's more than one correct way to write this — the exact wording of your message doesn't matter.
